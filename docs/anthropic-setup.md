# Налаштування Anthropic API (AI Service Layer)

## Що потрібно від Product Owner

1. Отримати `ANTHROPIC_API_KEY`.
2. Поповнити баланс на достатню для тестування суму.
3. Додати ключ у `.env.local` (не комітиться — див. `.env.example`).

## 1. Реєстрація та API-ключ

1. Відкрийте [console.anthropic.com](https://console.anthropic.com) і зареєструйтесь/увійдіть (окремий акаунт від claude.ai — Console призначена саме для розробників/API, не для чату).
2. **Settings → Billing → Add credits (or set up auto-reload)** — поповніть баланс. Для старту тестування з реальними користувачами достатньо **$5-10**: модель `claude-haiku-4-5` коштує $1/$5 за мільйон вхідних/вихідних токенів відповідно — це кілька тисяч викликів AI-функцій MenuMaker AI (кожен виклик — сотні-тисячі токенів, залежно від розміру меню).
3. **Settings → API Keys → Create Key**:
   - Назва: `menumaker-ai-production` (або `menumaker-ai-dev`, якщо плануєте окремий ключ для розробки — рекомендовано, щоб витрати/ліміти локальної розробки не змішувались із продакшн-використанням).
   - Скопіюйте ключ одразу — Console показує його лише один раз.
4. Вставте ключ у `.env.local`:
   ```
   AI_PROVIDER=anthropic
   ANTHROPIC_API_KEY=sk-ant-...
   ```

## 2. Ліміти та моніторинг витрат

- **Settings → Limits** — Anthropic Console дозволяє виставити місячний ліміт витрат (spending limit) на рівні акаунта. Рекомендую виставити ліміт відповідно до бюджету проєкту ($10-60/міс), щоб застосунок не міг випадково (через баг чи зловживання, попри rate limiting на нашій стороні) перевитратити бюджет.
- **Settings → Usage** — графік витрат по днях/моделях, зручно звіряти з логами `ai_call_succeeded` застосунку (`inputTokens`/`outputTokens` на кожен виклик — див. `docs/ai-service.md`).

## 3. Що вже реалізовано з нашого боку (не потребує дій PO)

- Rate limiting на рівні застосунку: не більше 10 AI-запитів/хв на користувача, незалежно від балансу кредитів.
- Система кредитів: кожен AI-виклик списує кредити з балансу користувача (`credits_balance`), ціни керуються таблицею `credit_costs` у Supabase (можна змінювати без деплою).
- Кожен виклик логується (модель, кількість токенів, тривалість, успіх/провал) — знадобиться, якщо треба буде звірити витрати Anthropic з фактичним використанням застосунку.

## 4. Зміна моделі в майбутньому

Модель захардкожена одним рядком у `src/services/ai/providers/anthropic-provider.ts` (`const MODEL = "claude-haiku-4-5-20251001"`). Апгрейд на потужнішу модель (наприклад Claude Sonnet) — свідома зміна цього рядка, без будь-яких інших правок коду.
