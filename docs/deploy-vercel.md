# Деплой на Vercel

## Статус

Готується до першого деплою (Stage 15.5). Домену ще немає — старт на `*.vercel.app`.

## 1. Свідомо відкладене: власний SMTP

Supabase's вбудований email-сервіс має суворий ліміт (`over_email_send_rate_limit`
ловився вже після ~3 листів під час тестування Stage 4) — непридатний для
реальних користувачів.

**Рішення (PO, Stage 15.5): відкладаємо.** Власний SMTP (Resend/SendGrid)
потребує домену для DNS-верифікації (SPF/DKIM) — домену поки немає.
Наслідок прийнято свідомо: **скидання пароля для email-користувачів не
працюватиме** на старті; Google OAuth — головний і повністю робочий шлях
входу. SMTP підключаємо разом із власним доменом, коли з'явиться попит.

Це відомий, свідомий gap — не недоробка. Не "чинити", доки не буде домену.

## 2. `maxDuration` на важких роутах

Vercel обмежує тривалість serverless-функції за замовчуванням коротше, ніж
може зайняти реальний виклик Anthropic, рендер PDF/PNG із фото, чи парсинг
файлу. На `next dev` цього ліміту немає — тому локально ніщо не натякає на
проблему; вона проявилась би вперше вже в проді, на реальному запиті.

Явно виставлено `export const maxDuration = 60;` (секунд) на 9 роутах:

- `POST /api/ai/analyze-menu`, `fix-text`, `generate-description`,
  `suggest-improvements`, `translate-menu` — один виклик Anthropic.
- `POST /api/menus/import` — парсинг файлу (PDF/DOCX/XLSX) + виклик AI в
  одному запиті.
- `POST /api/menus/[id]/export/pdf`, `export/png` — вбудовування шрифтів,
  багатосторінкова розкладка, для фото-орієнтованих розкладок — завантаження
  зображень.
- `POST /api/menus/[id]/photos/refresh` — по одному Pexels-запиту на страву
  (паралельно, але обмежено латентністю провайдера на великому меню).

`60` — свідомо обраний безпечний орієнтир, не виміряне число. **Не
перевірено живо** — на `next dev` немає штучного ліміту, який можна було б
відтворити. План: одразу після першого деплою прогнати реальний PDF-експорт
меню з фото і реальний AI-аналіз меню, зафіксувати фактичний час виконання
й переконатись, що план Vercel взагалі дозволяє виставлене значення (якщо
ліміт плану нижчий — Vercel або обріже, або поверне помилку білду; дізнаємось
одразу, не здогадуючись).

## 3. Env-змінні у Vercel

Project Settings → Environment Variables. Значення — ті самі, що в
`.env.local` (підтверджено PO — нових ключів Turnstile/Anthropic/Pexels
немає), крім `NEXT_PUBLIC_APP_URL`, якого ще не існує до першого деплою.

| Змінна                           | Джерело значення                                                                                                             |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `NEXT_PUBLIC_SUPABASE_URL`       | скопіювати з `.env.local`                                                                                                    |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY`  | скопіювати з `.env.local`                                                                                                    |
| `SUPABASE_SERVICE_ROLE_KEY`      | скопіювати з `.env.local`                                                                                                    |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` | скопіювати з `.env.local`                                                                                                    |
| `TURNSTILE_SECRET_KEY`           | скопіювати з `.env.local`                                                                                                    |
| `AI_PROVIDER`                    | `anthropic`                                                                                                                  |
| `ANTHROPIC_API_KEY`              | скопіювати з `.env.local`                                                                                                    |
| `PHOTO_PROVIDER`                 | `pexels`                                                                                                                     |
| `PEXELS_API_KEY`                 | скопіювати з `.env.local`                                                                                                    |
| `NEXT_PUBLIC_APP_URL`            | **URL, який Vercel видасть після першого деплою** — виставити другим кроком, не першим (курка-яйце: URL невідомий до деплою) |

## 4. Після першого деплою — що ще треба зробити

Залежить від реальної адреси, яку видасть Vercel — не можна зробити
заздалегідь. Чек-лист:

1. Скопіювати видану Vercel адресу (напр. `menumaker-ai.vercel.app`).
2. Виставити `NEXT_PUBLIC_APP_URL=https://<ця адреса>` у Vercel env vars,
   зробити redeploy (env-зміни не підхоплюються заднім числом).
3. **Google Cloud Console** → APIs & Services → Credentials → OAuth client
   → додати `https://<ця адреса>` в **Authorized JavaScript origins**
   (`localhost:3000` не видаляти). Redirect URI НЕ міняється — він завжди
   `https://vjwjdgdmwtpbyhowazpa.supabase.co/auth/v1/callback`.
4. **Cloudflare Turnstile Dashboard** → ваш сайт → додати `<ця адреса>` в
   список дозволених доменів (зараз лише `localhost`).
5. **`supabase/config.toml`**: додати `https://<ця адреса>/**` в
   `additional_redirect_urls`, запустити `supabase config push`.
6. Живий тест: реальний PDF-експорт меню з фото і реальний AI-аналіз меню
   на проді — зафіксувати фактичний час виконання (п. 2 вище).

Докладна інструкція крок-за-кроком для підключення репозиторію й отримання
адреси — у чаті з PO, не тут (одноразова дія, не довідковий матеріал).
